Understanding comes first

A captioned walkthrough of the actual learning workspace. These are demonstration and test accounts, not a longitudinal classroom study. Genuine 7/30-day scheduling is implemented; no delayed learning outcome is claimed.

Download PDF · Project video · Repository README

R1 · Reasoning evidence

Investigate the explanation

The learner identifies a flawed explanation, categorizes the issue and explains their thinking. Confidence and context add their perspective; a correct answer alone is not treated as proof of understanding.

Actual app capture: 03-investigation-1440-light.png

R2 · Learner agency

Keep more than one explanation open

Competing interpretations remain provisional. Evidence summaries and learner disagreement preserve what the system believed and what the learner says. These authored weights are not probabilities of ability.

Actual app capture: 04-interpretation-1440-light.png

R3 · Diagnostic interaction

Ask one useful next question

The selected probe asks for new evidence. Its rationale exposes competing predictions and the burden tradeoff. Different output, reading and unhurried probes test different possible explanations.

Actual app capture: 05-follow-up-1440-light.png

R4 · Supported learning

Make the reasoning visible

A worked example leads to a learner prediction and feedback. Learners read the feedback before continuing. A failed practice response leads to another example rather than an unsupported success label.

Actual app capture: 11-support-1440-light.png

R4 · Transfer

Apply the idea in a changed context

Transfer requires applying the rule to a different task. The learner supplies a repair, output and structured reasoning; failed checks return to support and fresh practice.

Actual app capture: 12-transfer-1440-light.png

R4 · Independent check

Check what the learner can do alone

Independent work removes current hints and answer reveals. The learner supplies a solution and reasoning. Filled fields are demonstration responses, not measured participant outcomes.

Actual app capture: 06-independent-1440-light.png

R4 · Reflection

Challenge an overgeneralized claim

A reflection task asks the learner to test a claim and justify a counterexample. Completion requires structured evidence across the investigation, rather than advancing after an incorrect response.

Actual app capture: 17-reflection-1440-light.png

R4 · Real elapsed time

Return after seven and thirty days

R4 · Adaptation

Keep the earlier evidence when support changes

The adaptation view preserves earlier and revised interpretations and directs the learner to changed support. Historical seeded examples are synthetic demonstrations; genuine delayed failures use separately persisted observations.

Actual app capture: 08-adaptation-1440-light.png

Teacher workspace

Review a learner’s reasoning history

Only an assigned teacher can inspect the learner’s evidence. The timeline preserves earlier reasoning and interpretations; pagination loads bounded pages across evidence types.

Actual app capture: 09-teacher-evidence-1440-light.png

Teacher roster

Find the student who needs your attention

Teachers can search their own students by username, hide sample accounts and navigate bounded roster pages. Search does not expose students from another class. Enrollment guidance points directly to the reusable class code.

Actual app capture: 24-teacher-roster-1440-light.png

Classroom extension

Create learning beyond the initial curriculum

Teachers can add subjects and lessons, then publish quizzes with answer keys and reasoning guidance. Students see only published quizzes in their assigned class and submit answers with explanations.

Actual app capture: 18-class-quiz-1440-light.png

Quiz recovery

Keep unfinished reasoning after a refresh

This real application capture follows a reload of an unfinished quiz. The answer and explanation are restored in the same tab, scoped to this learner and these questions. The draft is not submitted evidence and is cleared when submission succeeds or the learner signs out.

Actual app capture: 25-quiz-draft-1440-light.png

Human review of AI

Correct feedback without erasing its origin

This actual teacher review awards partial reasoning credit while preserving an incorrect answer. A student concern is resolved, the teacher’s reason stays in the audit trail, and the original AI feedback remains available.

Actual app capture: 23-teacher-feedback-review-1440-light.png

Evidence-informed next steps

Recommend a course to revisit

The classroom orders courses using the learner’s latest eligible quiz evidence. Teacher corrections refresh the stored course summary. This is an individual learning recommendation, not a ranking of students.

Actual app capture: 19-course-recommendations-1440-light.png

Responsive interface

Evidence and limits

Teacher corrections preserve original AI feedback and update recommendations. Learner perspectives remain revisable evidence. Public hosting is not verified; use local setup and downloadable artifacts. A genuine classroom pilot, difficulty calibration and production load study remain future validation work.
